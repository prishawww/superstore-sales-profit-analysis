# Superstore Sales & Profit Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Power BI dashboard** built to analyze sales and profit performance using the Superstore dataset.

The dashboard helps users understand business performance across different dimensions such as products, categories, regions, customers, sales, and profitability.

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall sales and profit performance
* Identify profitable and loss-making products
* Compare sales across categories and regions
* Understand customer and product performance
* Identify trends and patterns in business performance
* Present key business insights through an interactive dashboard

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query** for data preparation
* **DAX** for calculations and measures
* **Superstore Dataset**
* **GitHub** for project documentation and version control

## 📈 Dashboard Features

The dashboard provides interactive analysis of:

* Total Sales
* Total Profit
* Product Categories
* Sub-Categories
* Regional Performance
* Customer Performance
* Product Performance
* Sales and Profit Trends
* Profitability Analysis

Users can interact with the dashboard using filters and slicers to explore different parts of the dataset.

## 🔄 Data Preparation

The dataset was prepared and transformed using Power BI's Power Query functionality.

The data preparation process includes:

1. Importing the Superstore dataset
2. Cleaning and transforming the data
3. Checking data types
4. Preparing fields required for analysis
5. Creating calculated measures using DAX
6. Building interactive visualizations

## 🧮 Analysis

The dashboard focuses on business questions such as:

* How much sales and profit are being generated?
* Which categories generate the most sales?
* Which products are the most profitable?
* Which products or categories generate losses?
* Which regions perform best?
* How does profitability change across different segments?
* What areas of the business require attention?


## 🚀 How to Use

1. Download the Power BI dashboard file from this repository.
2. Open the file using **Power BI Desktop**.
3. Interact with the available filters, slicers, and visualizations.
4. Explore sales, profit, product, category, and regional performance.
